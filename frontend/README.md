# RoV Draft UI

React 19 + Vite + Tailwind CSS 4 draft board for the RoV draft model. The FastAPI app (`src/api.py`) serves the production build from `frontend/dist`.

## Development

```bash
# Terminal 1: API on :8000
uvicorn src.api:app --reload --port 8000

# Terminal 2: Vite dev server on :3000 (proxies /heroes, /predict, /draft, /health, /combat, /items-media to :8000)
cd frontend
npm install
npm run dev
```

## Production build

```bash
cd frontend
npm run build   # tsc + vite build -> frontend/dist
npm run lint    # oxlint
```

Then open `http://localhost:8000` with uvicorn running. The Docker image builds the frontend in its own stage.

## Layout

| Path | Purpose |
| :--- | :--- |
| `src/App.tsx` | Main application frame, tab router (Draft Board, Combat Lab `#lab`, Meta Lab `#meta`, Tier List `#tierlist`), and global keyboard shortcuts (`/` search, `Enter` lock #1, `Ctrl+Z` undo) |
| `src/api/client.ts` | Typed `getJson` / `postJson` with shared error handling and `AbortSignal` support. All API calls go through it |
| `src/hooks/useDraft.ts` | Hero catalog load, `/predict` calls; draft state lives in a `useReducer` with debounce session sync |
| `src/hooks/useCombatLab.ts` | State management and API interaction for Combat Lab duel simulation |
| `src/utils/draft.ts` | Pure draft logic: `draftReducer` (lock / undo / reset / predicted), `buildPredictPayload`, lane helpers |
| `src/types/draft.ts` | API types and canonical 18-step draft order (matches `DRAFT_STEPS` in `src/search/draft_mcts.py`) |
| `src/types/combat.ts` | Combat engine schemas, items, arcana, and enchantment types |
| `src/components/DraftBoardView.tsx` | Main draft board tab view |
| `src/components/ScoreBar.tsx` | Sticky win-probability bar, turn indicator, lookahead / undo / reset |
| `src/components/DraftTimeline.tsx` | 18-step ban/pick timeline |
| `src/components/TeamColumn.tsx` | Blue / red pick slots and ban strip |
| `src/components/AiPanel.tsx` | Top-5 recommendations, missing lanes, win trend, draft summary |
| `src/components/HeroGrid.tsx` | Searchable, role/lane-filtered hero grid |
| `src/components/HeroPortrait.tsx` | Square hero portrait with role/lane tags |
| `src/components/Modal.tsx` | Accessible dialog (Escape, backdrop click, focus trap, scroll lock, focus restore). Use it for every modal |
| `src/components/Alert.tsx`, `ErrorBoundary.tsx` | Shared error / warning banner; per-tab crash boundary |
| `src/components/DraftHistoryModal.tsx` | Multi-game series history modal with Global Ban tracking |
| `src/components/GlobalBanModal.tsx` | Series global ban configuration modal |
| `src/components/NewSeriesModal.tsx` | New series configuration dialog |
| `src/components/lab/` | **Combat Lab** (`#lab`): 1v1 duel simulator, build panel, item card viewer, rich hero skill modal, stat sheet, level sweep |
| `src/components/meta_lab/` | **Meta Lab** (`#meta`): competitive tournament meta telemetry, flex-pick analytics, duo synergies |
| `src/components/tierlist/` | **Tier List** (`#tierlist`): interactive tier list with lane filtering and patch badges |
| `src/utils/heroNames.ts` | Thai server display names (e.g. Mortos, Celica, Riktor). API and model keep canonical names |
| `public/avatars/` | 130 square hero icons, regenerated by `scripts/fetch_hero_icons.py` |
| `public/items/` | 114 item icons (scripts/fetch_item_icons.py) |
| `public/skills/` | Hero skill icons |
| `public/enchantments/` | 33 enchantment icons |
| `public/hero_images.json` | Hero name -> avatar path, also read by the API for `/heroes` |
